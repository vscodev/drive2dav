# 许可证

你可以通过[爱发电](https://ifdian.net/a/vscodev)平台来购买 [Drive2dav 许可证](https://ifdian.net/item/fdd222e0888811ec8d2852540025c377)，支付成功后许可证密钥会自动通过私信发送给你。

激活许可证需要联网，设备时间和网络时间的误差不得超过 90 秒。每个许可证密钥最多可激活 3 台设备，支持[反激活](https://www.drive2dav.top/license)。

> [!NOTE]
> Drive2dav 可能会随版本迭代更新授权策略，届时许可证状态可能会失效，你需要升级到最新版并使用许可证密钥重新激活。购买即表示你同意该条款。
