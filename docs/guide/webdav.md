# WebDAV

Drive2dav 在本地维护了一个虚拟的文件系统，能大幅降低对网盘接口的请求频率，从而确保 WebDAV 服务安全高效运行。

## 连接配置

| Name   | Value                     |
|--------|---------------------------|
| URL    | `http[s]://host:port/dav` |
| 主机   | `host`                    |
| 路径   | `/dav`                    |
| 协议   | `http[s]`                 |
| 端口   | `port`                    |
| 用户名 | 与网页端一致              |
| 密码   | 与网页端一致              |
