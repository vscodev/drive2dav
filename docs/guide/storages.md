# 添加存储

请参考下方的配置说明添加并挂载相应存储，挂载成功后就可以通过 [WebDAV](/guide/webdav) 连接并访问了。

![mount](/images/mount.webp)

> [!TIP]
> 挂载的根文件夹名称是存储的唯一标识，它对应根目录`/`下的一级文件夹。

## 通用项

### 刷新间隔

你可以通过配置该参数让程序在获取文件列表时自动更新并重建文件索引，如果文件源经常变动请设置为较小的值，反之则设置为较大的值。`0` 表示禁止自动更新。

### 强制代理

当存储驱动为网盘时，如果上游支持，Drive2dav 默认会通过重定向的方式访问文件资源，不消耗服务器流量。

但某些网盘可能不支持跨域访问，或者返回的 MIME 类型不正确，导致浏览器无法阅览/播放，这种情况下你可以启用【强制代理】，使用服务器进行中转。

## Google Drive

### 根文件夹 ID

文件夹的唯一标识，可从浏览器地址栏获取。

目标文件夹对应 URL `https://drive.google.com/drive/folders/1Qd9RC5Lr0J7VHUssBSv5sKDhxnla_GSs` 最后面的一串字符

## WebDAV

### 服务器地址

如果你希望添加某个特定的文件夹而不是根目录，请在服务器地址后面拼接对应的路径。比如上游提供的 WebDAV 服务器地址为
`https://dav.jianguoyun.com/dav/` ，目标文件夹为 `/Movies` ，对应的服务器地址请填写
`https://dav.jianguoyun.com/dav/Movies` 。
