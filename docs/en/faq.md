# FAQ

## The program fails to start after an update. What should I do?

Drive2dav occasionally ships breaking updates. If the program misbehaves after an update, you can run `drive2dav prune` to clear the application data and reinitialize.

> [!TIP]
> On Windows, if you are not comfortable with the command line, type `%AppData%` in the Explorer address bar and press Enter, then delete the `drive2dav` folder.

## I forgot the administrator password. What should I do?

Run `drive2dav admin reset-pwd` to reset it.
