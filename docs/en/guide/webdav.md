# WebDAV

Drive2dav maintains a virtual file system locally, which greatly reduces the request rate against cloud drive APIs and keeps the WebDAV service fast and safe.

## Connection settings

| Name     | Value                     |
|----------|---------------------------|
| URL      | `http[s]://host:port/dav` |
| Host     | `host`                    |
| Path     | `/dav`                    |
| Protocol | `http[s]`                 |
| Port     | `port`                    |
| Username | Same as the web UI        |
| Password | Same as the web UI        |
