# 认证配置

对应配置文件的 `auth` 项。

| 字段               | 类型   | 默认值   | 说明                                                                                         |
|--------------------|--------|----------|----------------------------------------------------------------------------------------------|
| `jwt_secret`       | string | 自动生成 | 登录令牌的签名密钥，首次启动时随机生成。**请勿泄露或随意修改**，修改后所有用户需要重新登录。 |
| `token_expires_in` | int    | `7`      | 登录令牌的有效期（**天**）。                                                                 |
